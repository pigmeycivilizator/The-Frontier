Download the basic *STALKER SoC* first, then download this repo, rename it to **gamedata** and put it inside the game folder.
It should sit alongside the gamedata.db files.

The rest of the files can be dowloaded [here](https://drive.google.com/drive/folders/1BQFBQETx40yGPz1sGN0cSjALEXs6iA2b?usp=sharing): 
1. [bin_x64](https://drive.google.com/drive/folders/1BQFBQETx40yGPz1sGN0cSjALEXs6iA2b?usp=sharing) - should go to the base folder, alongside your **gamedata** folder.
2. [textures](https://drive.google.com/drive/folders/1BQFBQETx40yGPz1sGN0cSjALEXs6iA2b?usp=sharing) - should go directly into **gamedata**
3. [ui](https://drive.google.com/drive/folders/1BQFBQETx40yGPz1sGN0cSjALEXs6iA2b?usp=sharing) - should go into **gamedata/config/misc/**. - **NOTE:** skip this part, and try to lauch the game without this one.
4. [fsgame.ltx](https://drive.google.com/drive/folders/1BQFBQETx40yGPz1sGN0cSjALEXs6iA2b?usp=sharing) - should go into the base folder.

Unpack all .zip archives before putting them anywhere.

After doing the above steps launch the game: **bin_x64/xrEngine.exe**
